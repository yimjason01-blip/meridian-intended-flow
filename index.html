Meridian intended onboarding flow

Baseline first. Conversation second. Cadence forever.

The first physician visit should not be spent deciding what data to collect. Meridian collects the minimum complete baseline first, then uses the visit for decisions that change risk, function, and follow-up cadence.

Design rule

One coordinated baseline beats a clever fragmented baseline. Mobile phlebotomy is the default. Capillary kits belong in focused rechecks, not first-pass onboarding.

What changed from the old flow

Baseline is no longer split across a home capillary kit and a separate lab visit. First-pass onboarding uses mobile venous collection where available.

What genetics does

Genetics informs surveillance, imaging, and interpretation. It rarely changes the core blood panel, so it should run in parallel.

What the first visit is for

Not ordering more basics. The visit is for decisions: what to act on, what to monitor, and what not to over-medicalize.
